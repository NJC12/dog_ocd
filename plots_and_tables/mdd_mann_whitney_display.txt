Dog-set Mann–Whitney tests for this trait. Significant, suggestive and combined TOGA sets contain 43, 40 and 83 genes; each is compared with non-dog covered genes. The one-sided alternative is stronger association in dog genes. P(dog stronger) counts tied pairs as one-half. Holm correction applies only to the six OCD tests across two windows and three dog sets; control traits have blank Holm values.

Rows: 6. Tab-separated UTF-8 text with one header row. Numeric values retain computational precision rather than notebook display rounding. Blank fields indicate missing or inapplicable values.

Columns
Window: TSS window: 1mb is ±1 Mb; 500kb is ±500 kb, inclusive.
Dog set: Dog set; see the table context above.
Dog genes: Number of covered genes in the selected dog subset.
Non-dog genes: Number of background genes: non-dog for dog tests, all other genes for Human-set tests.
U: Mann–Whitney U for the selected set versus its background, using association strength.
P(dog stronger): Probability a dog gene has stronger association than a non-dog gene, counting ties as one-half.
One-sided p: One-sided asymptotic Mann–Whitney p-value testing stronger association in the selected set.
Holm p: Holm-adjusted p-value; dog tests use six OCD tests only (control traits blank); Human-set tests use a separate 12-test family.
