# Data organization

External inputs and locally generated data are kept separate. Files were moved
without changing their contents; the old/new paths and SHA-256 checksums are in
`generated/reorganization_manifest.json`. The locally assembled GWAS checksum
registry was updated to use the new paths, with its before/after hashes recorded.

## External inputs: `downloaded/`

| Folder | Contents | Used by |
| --- | --- | --- |
| `gwas/` | Six original compressed human GWAS summary-statistics files. OCD, BIP, ADHD, MDD and SCZ have source GRCh37 positions; harmonized CAD uses GRCh38. | Main notebook and window-scoring scripts. |
| `annotation/` | GENCODE v50 comprehensive GRCh38 GTF. | Gene/TSS annotation in the notebook and legacy pipeline. |
| `supplementary/` | Original `NATURE_SupplementaryTables.xlsx`, including ST5/ST6. | TOGA Dog and ST6 Human membership; constraint analysis. |
| `burden/` | Supplied OCD pLoF SKAT-O gene-burden CSV. | Separate `src/compare_burden.py`; absent from the notebook. |
| `orthology/` | Cached Ensembl REST JSON responses and BioMart TSV. These are external query responses, not locally inferred orthology. | Legacy Ensembl-confirmed 78-gene pipeline. |
| `metadata/` | Publisher READMEs, CAD YAML, ADHD PDF, Figshare API snapshots and OCD cohort-metadata XLS. | Provenance and coordinate-build documentation. The cohort XLS is not SNP summary statistics. |
| `constraint/` | Supplementary Agarwal gene-to-Ensembl map retained from earlier work. | Reference only; current constraint code does not read it. |

Each original external file has a companion named `<complete filename>.txt`
explaining its provenance, contents and use. For example, a `.gz` input has a
`.gz.txt` companion, and an original source `.txt` has a `.txt.txt` companion;
this preserves original publisher text. These companion documents are local
documentation, not additional external data. Missing acquisition dates and
unverified origins are stated explicitly rather than inferred from file times.

## Generated data: `generated/`

1. `mapped_grch38/chr1.parquet` through `chr22.parquet` cache OCD SNPs after
   validation and UCSC GRCh37-to-GRCh38 liftover. Each contains `pos` (1-based
   GRCh38), `p` (association p-value) and `snp` (identifier), sorted by position.
   Rebuild with `src/preprocess_gwas.py`, or the notebook's rebuild options.
2. `source_metadata/` contains MDD/SCZ header lines extracted from the original
   compressed GWAS files. These are derived metadata, not separate downloads.
3. `gwas_manifest.json` is the local six-trait input registry: project-relative
   path, publisher-verified MD5 and byte size. It is not a publisher data file.
4. `reorganization_manifest.json` records input/config moves and content hashes.
   Historical audit records retain their original paths; consult this manifest
   to resolve them. Archived notebooks also retain their historical source text.
5. `reorganization_validation.json` records checks of moved-file hashes,
   provenance coverage, source documentation, exports and notebook execution.

## Generated scientific results

`../notebook/results/` contains generated scores, tests, figures and methods.
The current TOGA notebook writes `../notebook/results/ipynb/toga/`, and its
constraint section writes `../notebook/results/shet/`. Earlier scores and rank
tables remain inputs to reproduction checks; they are not disposable just
because newer results exist. The pLoF burden analysis has separate outputs in
`../notebook/results/burden/`.

`../plots and tables/` contains the main notebook's delivery exports: PDF plots
and TSV tables with same-stem TXT explanations. They can be regenerated by
executing the notebook using the preserved inputs and caches.

## Shared inputs outside this project

The existing shared inputs remain in place:

1. `~/data/liftover/hg19ToHg38.over.chain`: UCSC hg19-to-hg38 chain used by
   `src/compare_ocd.py` and the notebook. Source distribution:
   https://hgdownload.soe.ucsc.edu/goldenPath/hg19/liftOver/hg19ToHg38.over.chain.gz
   The local file is uncompressed. Chain-coordinate intervals are 0-based;
   scoring inputs/outputs use 1-based SNP positions. The exact chain checksum
   is recorded in psychiatric summary JSONs under `notebook/results/`.
2. `~/data/constraint/shet/agarwal/`: the Agarwal loss-of-function fitness-effects
   reference used by `src/compare_shet.py`. Required files are
   `elife-83172-supp2-v2.txt` and `posterior_densities.*.txt.gz`. The summary maps
   genes to transcripts/chromosome groups; posterior files provide densities on
   a log10(s_het) grid. Source:
   https://github.com/agarwal-i/loss-of-function-fitness-effects
   File SHA-256 checksums are recorded in `notebook/results/shet/shet_audit.json`.

These shared files were neither moved nor modified. They must be supplied at the
configured paths when reproducing this project on another machine.

## Public repository

Bulk GWAS/annotation downloads, the All by All burden CSV, and all generated
`notebook/results/burden/` outputs are excluded from GitHub. Their local copies
are preserved. All by All associations can be viewed in
https://allbyall.researchallofus.org/ using phenotype code
`obsessive_compulsive_disorder` (ancestry `meta`, pLoF, MAF < 0.001); see its FAQ
before downloading. The tracked burden TXT explains the source and restrictions.

The supplementary workbook was compared against the owner's download from
https://www.biorxiv.org/content/10.64898/2026.10.12.758413v1.supplementary-material.
ST5/ST6 are identical in content; the workbook TXT records the other minor
differences and the comparison report. Original input checksums and historical
validation counts describe the complete local workspace, including inputs that
are not distributed through GitHub.
