Pyshciatric Genomics Consortium (PGC) GWAS Meta-analysis of Bipolar Disorder
Results from: O'Connell et al., Under Review. Preprint available on medRXiv https://www.medrxiv.org/content/10.1101/2023.10.07.23296687v1

Files prepared by: Kevin O'Connell k.s.oconnell@medisin.uio.no

GWAS results are in Ricopili daner format. For column description see: https://docs.google.com/document/d/1TWIhr8-qpCXB13WCXcU1_HDio8lC_MeWoAg2jlggrtU/edit. 
Genome build is hg19. 
SNPs present in < 75% of total effective sample size from the meta-analysis have been removed from these files. 
SNPs were retained only if cohort MAF was >1% and minor allele count was >10 in either cases or controls (whichever had smaller n). 
We employed the DENTIST tool (https://github.com/Yves-CHEN/DENTIST) to detect and filter out problematic variants 
Allele frequencies provided are for A1 from the HRC reference panel corresponding to the ancestry including in the meta-analysis (EUR - EUR, AFR - AFR, EAS - EAS, LAT - AMR). For the multi-ancestry meta-analysis the allele frequencies for A1 from all four reference panels are provided.
